# Project 10: Brief to Prototype

> **Confidential. Covered by your NDA.** Do not share this brief, copy it into a public repository, or describe what REMAP assigns. The work you write is yours; the brief is not.

Five clients, five industries, five days. For each one you take a two-line brief, scope it, design it, direct an AI coding agent to build a working prototype, and present it back as if the client were in the room. Alongside the five, you document your own AI development pipeline: how AI fits into each stage of your work, and how you manage its context.

| | |
|---|---|
| **Tier** | Mid |
| **Timeline** | 7 working days from the day you create your copy |
| **Trains** | System Design, AI Tooling and Workflow, Independent Operation, Client and Communication |
| **You finish with** | Five documented prototypes, an AI pipeline diagram, and a live review |
